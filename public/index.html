Передача между устройствами

Откройте сервис на обоих устройствах (браузер, без установки ПО), соедините по коду или QR. Файлы между устройствами одной сети идут напрямую (WebRTC), иначе — через короткий облачный ретранслятор. Данные эфемерные: сообщения и файлы стираются при закрытии комнаты.
