# Toolbox

Мини-сервис из трёх инструментов в одном приложении + базовая защита доступа.

1. **Короткие ссылки** — сокращение URL с подсчётом переходов и QR-кодом для каждой ссылки. Список хранится на диске (`/data/links.json`), переживает рестарт.
2. **QR-генератор** — QR для любого текста или URL (сервер выдаёт PNG через `/qr?data=...`).
3. **Передача между устройствами** — обмен файлами и текстами по коду из 6 символов или QR-приглашению. Каждое устройство открывает сайт в браузере — устанавливать ничего не нужно (без ПО).
   - Если устройства в одной сети — файлы идут напрямую между браузерами (WebRTC P2P, скорость локалки).
   - Если прямой канал не пробивается — файл грузится на сервер комнаты (ретранслятор) и остаётся доступным остальным участникам.
   - Комнаты живут до 6 часов / 30 минут без активности; сообщения и файлы эфемерные (данные файлов хранятся в `/tmp` контейнера).

## Защита доступа

Стартовой блокировки нет: главная страница и короткие ссылки открыты сразу. Во вкладке «Доступ» есть тумблер **«Требовать вход для QR-кодов и комнат передачи»**. Пока он выключен, QR и комнаты тоже открыты. При включении задаётся мастер-пароль, и это устройство становится доверенным.

Для защищённых QR/комнат можно использовать несколько способов входа:

| Способ | Как работает |
|---|---|
| **Мастер-пароль** | Обычный вход по паролю на любом устройстве |
| **PIN-код** | 4–12 цифр для быстрого входа |
| **Подтверждение устройства** | Новое устройство отправляет запрос; на доверенном устройстве во вкладке «Доступ» его можно разрешить или отклонить |
| **Одноразовые приглашения** | QR/ссылка на 10 минут, одноразовая — идеально для телефона, чтобы не вводить пароль |
| **Управление устройствами** | Список доверенных устройств, отзыв доступа, выход |

Публичными всегда остаются главная страница, короткие ссылки (`/s/<id>`), `/healthz` и API ссылок. При включённой защите `/qr` и `/api/transfer/*` требуют cookie-сессию доверенного устройства; управление доступом тоже доступно только после входа. Пароли и PIN хранятся в виде соли + SHA-256 (`/data/auth.json`).

## Запуск

```sh
npm install
npm start        # http://localhost:3000
```

Docker: `Dockerfile` в корне (Node 20, порт 3000).

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт HTTP-сервера |
| `TOOLBOX_ADMIN_PASS` | — | Задать мастер-пароль из окружения (тогда первичная настройка не нужна) |
| `MAX_FILE_MB` | `100` | Лимит одного файла при загрузке |
| `BASE_URL` | авто | Явный базовый URL для построения ссылок |

Хостинг: заточен под [Deplexo](https://deplexo.com). Free-план: одно приложение, 0.25 CPU / 128 МБ RAM / 250 МБ диска; постоянный том `/data` — для ссылок и настроек доступа, эфемерный `/tmp` — для файлов комнат.
