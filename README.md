# Toolbox

Мини-сервис из трёх инструментов в одном приложении:

1. **Короткие ссылки** — сокращение URL с подсчётом переходов и QR-кодом для каждой ссылки. Список хранится на диске (`/data/links.json`), переживает рестарт.
2. **QR-генератор** — QR для любого текста или URL (сервер выдаёт PNG через `/qr?data=...`).
3. **Передача между устройствами** — обмен файлами и текстами по коду из 6 символов или QR-приглашению. Каждое устройство открывает сайт в браузере — устанавливать ничего не нужно (без ПО).
   - Если устройства в одной сети — файлы идут напрямую между браузерами (WebRTC P2P, скорость локалки).
   - Если прямой канал не пробивается — файл грузится на сервер комнаты (ретранслятор) и остаётся доступным остальным участникам.
   - Комнаты живут до 6 часов / 30 минут без активности; сообщения и файлы эфемерные (данные файлов хранятся в `/tmp` контейнера).

## Запуск

```sh
npm install
npm start        # http://localhost:3000
```

Docker: `Dockerfile` в корне (Node 20, порт 3000).

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт HTTP-сервера |
| `TOOLBOX_TOKEN` | off | Если задать — список/удаление ссылок требуют заголовок `x-toolbox-token` |
| `MAX_FILE_MB` | `100` | Лимит одного файла при загрузке |
| `BASE_URL` | авто | Явный базовый URL для построения коротких ссылок |

Хостинг: заточен под [Deplexo](https://deplexo.com) (фритир: один контейнер, постоянный том `/data` для ссылок, эфемерный `/tmp` для файлов).
